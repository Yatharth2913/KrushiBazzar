# 🌾 Krushi Bazzar

Krushi Bazzar is a web-based platform developed to connect farmers directly with customers. It helps farmers sell their agricultural products without middlemen, ensuring better prices and a transparent marketplace.

## 📌 Features

- Farmer Registration & Login
- Customer Registration & Login
- Product Listing
- Search Products
- Product Categories
- Responsive Design
- Contact Page

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Node.js
- Express.js
- MongoDB
- Mongoose
- Git
- GitHub
- Responsive Web Design
- Visual Studio Code (VS Code)

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/yatharth2913/Krushi-Bazzar.git
```

2. Open the project folder

```bash
cd Krushi-Bazzar
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
npm start
```

## 🎯 Objective

To create an online marketplace where farmers can directly sell their products to customers, reducing dependency on intermediaries and improving farmers' income.
